# Project Structure

*A clean way to arrange a backend project*

```
my-app/
├── node_modules/
├── src/
│   ├── routes/       → URLs
│   ├── controllers/  → what to do for each URL
│   ├── models/       → database shapes
│   └── utils/        → helper functions
├── .env
├── .gitignore
├── package.json
└── server.js         → starts the app
```

> You'll use this with **Express + MongoDB**.
