# Status Codes

*A number that tells the result*

| Range | Meaning | Common |
|---|---|---|
| **1xx** | Info | |
| **2xx** | Success ✅ | `200` OK · `201` Created · `204` No Content |
| **3xx** | Redirect | `301` Moved · `304` Not Modified |
| **4xx** | Client mistake ❌ | `400` Bad Request · `401` Unauthorized · `403` Forbidden · `404` Not Found |
| **5xx** | Server mistake 💥 | `500` Internal Server Error · `503` Unavailable |

> Easy trick : **4xx = your fault, 5xx = my fault** (server).
