# REPL 🔁

*Try JS directly in the terminal*

> 💡 **REPL** = **R**ead → **E**valuate → **P**rint → **L**oop

## ⌨️ Try it

Type `node` and press Enter :

```bash
$ node
> 2 + 3
5
> "hi".toUpperCase()
'HI'
> _
'HI'
> .exit
```

## 📌 Key Points

- ⚡ Good for **quick testing** of small code.
- ↩️ `_` gives the **last result**.
- 🚪 Exit with `.exit` or **Ctrl + C** two times.

## 🆚 REPL vs `.js` file

| | Use it for |
|---|---|
| 🔁 **REPL** | quickly **testing** code |
| 📄 **`.js` file** | **writing & saving** code |
