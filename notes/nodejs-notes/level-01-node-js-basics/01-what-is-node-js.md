# What is Node.js? 🟢

*JavaScript that runs outside the browser*

> 💡 **Node.js** is a **JavaScript runtime environment**. It lets us run JavaScript **outside a web browser**, like on our **computer** or a **server**.

```bash
node app.js    # your computer runs app.js, no browser needed
```

## 🕰️ Before Node.js

- 🌐 JavaScript ran **only inside web browsers**.
- ✨ It was mainly used to make web pages **interactive**.

## 🚀 What can we build with Node.js?

| | What | Example |
|---|---|---|
| 🖥️ | **Backend servers** | the server behind a website |
| 🔌 | **APIs** (let different apps **talk to each other**) | weather app asks a server for weather data |
| ⌨️ | **CLI tools** | programs you run in the terminal |
| 💬 | **Real-time apps** | chat apps, live notifications |

## ⚙️ How does Node.js work?

Node.js uses Google's **V8 engine** 🏎️, the same JavaScript engine used by **Chrome**.

## 📌 Important Points

- ❌ Node.js is **not a programming language**.
- ❌ Node.js is **not a framework**.
- ✅ Node.js is a **runtime environment** for running JavaScript.
