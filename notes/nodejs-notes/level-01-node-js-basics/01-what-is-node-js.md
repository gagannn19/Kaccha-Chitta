# What is Node.js?

*Node.js is a JavaScript runtime environment that allows us to execute JavaScript code outside the browser, such as on a computer or server.*

- Before Node, JS could run **only inside the browser**.
- **Node.js** lets you run JS on your **computer / server**.
- It is **not a language** and **not a framework**. It is a **runtime** (a place where JS code runs).
- Built on Google Chrome's **V8 engine** (the same engine that runs JS in Chrome).

**Used for :** backend servers, APIs, CLI tools, real-time apps (chat).

> Simple line : **Node.js = V8 engine + extra features (files, network, OS)**
