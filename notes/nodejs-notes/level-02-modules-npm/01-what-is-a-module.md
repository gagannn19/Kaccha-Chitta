# What is a Module?

*One file = one module*

- Putting all code in one file gets messy.
- So we **split code into files**. Each file is a **module**.
- A module can **export** things, other files can **import** them.

**3 types of modules :**

1. **Your own** → files you write (`./math.js`)
2. **Built-in (core)** → come with Node (`fs`, `path`, `http`)
3. **Third-party** → installed from npm (`express`, `lodash`)
