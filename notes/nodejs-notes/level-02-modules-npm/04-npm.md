# npm

*Node Package Manager*

- **npm** = an app store for JS code (**packages**).
- Comes free with Node.
- Lakhs of ready-made packages at **npmjs.com**.

```bash
npm init -y            # create package.json
npm install express    # install a package (short : npm i express)
npm uninstall express  # remove it
npm i -g nodemon       # -g = install globally (use anywhere)
```

> **npx** → run a package **without installing** it : `npx create-react-app`
