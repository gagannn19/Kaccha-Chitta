# New in React 19

- **Actions** - async functions in transitions & forms : `<form action={saveAction}>`
- **useActionState** - pending state + result of a form action
- **useOptimistic** - show the result instantly, before the server replies
- **use()** - read a promise or context while rendering
- **ref** can be passed as a normal prop - no forwardRef needed

> **Note :** Your ReactTasks project uses React 18 - everything in Levels 1-10 works the same in 19.
