# ⚡ Setup with Vite

*Create a React project in seconds* 🚀

## 🛠️ 4 steps to start

```bash
npm create vite@latest my-app   # 1️⃣ make the project (choose React + JavaScript)
cd my-app                       # 2️⃣ go inside the folder
npm install                     # 3️⃣ download the packages
npm run dev                     # 4️⃣ start it → http://localhost:5173
```

> 💡 `npm create vite` makes a new folder named **my-app** with all the project files.

## 💻 Handy terminal commands

| Command | What it does |
|---|---|
| `mkdir my-app` | 📁 make a folder |
| `cd my-app` | 🚪 go inside the folder |
| `ls` | 👀 see what's inside |

## 🗂️ Vite Project Structure

```
my-app/
├── index.html        📄 the ONE HTML page (entry point)
├── src/
│   ├── main.jsx      🚦 starts the React app
│   ├── App.jsx       🏠 the main (root) component
│   └── index.css     🎨 global styles
├── package.json      📋 project info + list of packages
└── node_modules/     📦 downloaded packages (don't touch!)
```

> ✍️ You'll write most of your code inside **`src/`**.
