# Component Tree

*Every React app is a tree of components*

```
App
├── Navbar
│   ├── Logo
│   └── Links
├── ProductList
│   ├── ProductCard
│   └── ProductCard
└── Footer
```

- **App** is the root
- Parents render children
- Data flows from top to bottom (Level 2)
