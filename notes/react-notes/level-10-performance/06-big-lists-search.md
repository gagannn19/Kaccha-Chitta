# Big Lists & Search

- **Virtualization** - render only the ~20 rows visible on screen, not all 10,000 (react-window)
- **Pagination** or **Infinite scroll** (IntersectionObserver) - load data in chunks
- **Debounced search** - call the API after typing stops (useDebounce)
- **Throttled scroll** handlers
- **Skeleton loading UI** - looks faster than a spinner
- Stable **keys** so React doesn't re-create list items
