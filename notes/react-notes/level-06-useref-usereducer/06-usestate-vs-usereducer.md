# useState vs useReducer

|  | useState | useReducer |
|---|---|---|
| Best for | simple values (number, string, boolean) | objects / arrays with many actions |
| Update logic | spread across handlers | in one reducer function |
| Example | toggle, input text, counter | cart, todo list, multi-step form |
