# colspan attribute

`colspan="n"`

used to create cells which spans over multiple columns

```html
<tr> <th colspan="2"> Data </th> </tr>
<tr> <td> Shradha </td> <td> 1664 </td> </tr>
<tr> <td> Aman </td>    <td> 1890 </td> </tr>
```
