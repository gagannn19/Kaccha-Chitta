# thead & tbody in Tables

`<thead>` to wrap table head

`<tbody>` to wrap table body

```html
<table>
  <thead>
    <tr> <th> Name </th> <th> Roll No </th> </tr>
  </thead>
  <tbody>
    <tr> <td> Shradha </td> <td> 1664 </td> </tr>
  </tbody>
</table>
```
