# Tables in HTML (Example)

```html
<table>
  <tr>
    <th> Name </th>
    <th> Roll No </th>
  </tr>
  <tr>
    <td> Shradha </td>
    <td> 1664 </td>
  </tr>
</table>
```

![table output](../images/table-out.png)

> 💡 Borders don't show by default. Add them with CSS: `table, th, td { border: 1px solid black; }`
