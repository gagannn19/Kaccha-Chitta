# Heading Tag

Used to display headings in HTML.

| Tag | |
|---|---|
| `h1` | (most important) |
| `h2` | |
| `h3` | |
| `h4` | |
| `h5` | |
| `h6` | (least important) |

```html
<h1>Heading 1</h1>
<h2>Heading 2</h2>
...
<h6>Heading 6</h6>
```

![h1 to h6 output](../images/headings-out.png)

> 💡 Use only **one `<h1>`** per page (like one title per book).
