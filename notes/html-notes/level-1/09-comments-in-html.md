# Comments in HTML

This is part of code that should not be parsed.

```html
<!-- This is an HTML Comment -->
```

![comments are invisible](../images/comment-out.png)

> ⌨️ Shortcut in VS Code: `Ctrl + /` comments / uncomments a line.
