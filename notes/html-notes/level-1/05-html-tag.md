# HTML Element

An HTML element is a complete structure that usually consists of an opening tag, content, and a closing tag. It can also contain other HTML elements. However, some elements, such as ```<img>``` and ```<br>```, do not have closing tags.

# HTML tag

An HTML tag is a keyword enclosed in angle brackets (< >) used to define HTML elements.

```html
<p> This is a paragraph </p>
```
