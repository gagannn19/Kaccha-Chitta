# Revisiting Image Tag

```html
<img src="link" height="50">
```

→ set height

```html
<img src="link" width="50">
```

→ set width

![height and width output](../images/img-size-out.png)

> 💡 Give only one of height or width, and the image keeps its shape (no stretching).
