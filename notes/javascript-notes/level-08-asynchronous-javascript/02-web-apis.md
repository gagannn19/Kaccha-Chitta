# Web APIs

*Browser superpowers - NOT part of JavaScript*

BrowserJS Engine (Call Stack + Heap)Web APIs (setTimeout, DOM, fetch, localStorage, console)

- JS reaches them through the global object **window**
- **setTimeout()** is really **window.setTimeout()** - even console.log is a Web API!
