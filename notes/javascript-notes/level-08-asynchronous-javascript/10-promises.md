# Promises

*An object for a value that will arrive in the future*

Pending (waiting...) Fulfilled (resolve(value) → .then)Rejected (reject(error) → .catch)

- A promise starts **pending**, then settles ONCE : fulfilled or rejected
- Its state can never change again - it is **immutable**

> **Example :** Like a token at a food counter. Now it says 'waiting', later 'ready' or 'sorry, out of stock'.
