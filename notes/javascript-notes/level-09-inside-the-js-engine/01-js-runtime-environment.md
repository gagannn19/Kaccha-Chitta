# JS Runtime Environment

*Everything needed to run JS*

JS Runtime Environment (Browser / Node.js) JS Engine (Heap + Call Stack)Web APIsEvent LoopCallback QueueMicrotask Queue

- The **engine** runs JS. The **runtime** gives it extra powers (timers, DOM, files)
- Engines : **V8** (Chrome, Node.js), **SpiderMonkey** (Firefox - the first JS engine), **JavaScriptCore** (Safari)
- **ECMAScript** = the rulebook all engines follow (ES6 = 2015)
