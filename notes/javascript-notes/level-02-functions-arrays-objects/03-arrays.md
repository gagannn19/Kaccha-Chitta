# Arrays

*An ordered list of values*

```js
const nums = [10, 20, 30];
nums[0];          // 10
nums.length;      // 3

nums.push(40);    // add at end      [10, 20, 30, 40]
nums.pop();       // remove from end [10, 20, 30]
nums.unshift(5);  // add at start    [5, 10, 20, 30]
nums.shift();     // remove start    [10, 20, 30]
nums.includes(20);// true
nums.indexOf(30); // 2
```
