# Console & Comments

*Your best debugging friend*

```js
console.log("Hello World");   // prints in the browser console
console.log(2 + 3);           // 5
console.error("Oops");        // red error message
console.table([1, 2, 3]);     // shows data as a table

// single line comment
/* multi
   line comment */
```

> **Tip :** Open the console with Right click > Inspect > Console (or F12).
