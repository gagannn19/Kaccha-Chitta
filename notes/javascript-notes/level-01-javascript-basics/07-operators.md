# Operators

```js
// Arithmetic
5 + 2   // 7
5 % 2   // 1  (remainder)
2 ** 3  // 8  (power)

// Assignment
let x = 5;
x += 2;   // x = 7
x++;      // x = 8
```

```js
// Comparison
5 > 3      // true
5 == "5"   // true  (converts type)
5 === "5"  // false (strict)
5 !== 6    // true

// Logical
true && false  // false
true || false  // true
!true          // false
```

> **Rule :** Always use === and !== to avoid surprises.
