# == vs ===

*Loose equality converts types first*

```js
0 == ""          // true
0 == "0"         // true
null == undefined// true
false == "0"     // true

0 === ""         // false
null === undefined // false
```

- **==** converts both sides to the same type, then compares (type coercion)
- **===** compares value AND type - no conversion

---

## 🔍 `===` (strict)

*Same type and same value → `true`*

```js
5 === 5       // true
5 === "5"     // false  (number vs string)
true === 1    // false  (boolean vs number)
```

---

## 🔄 `==` (loose)

*Converts to the same type, then compares*

```js
5 == "5"      // true   ("5" becomes 5)
true == 1     // true   (true becomes 1)
false == 0    // true   (false becomes 0)
null == 0     // false  (null is only == to undefined)
```

---

## 🚫 Two special cases

```js
NaN === NaN   // false  <- NaN is never equal, not even to itself
[] === []     // false  <- two different arrays
```

---

> **Rule :** Always use `===` and `!==` to avoid surprises.
