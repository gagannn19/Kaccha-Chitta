# Data Types

*7 primitive types + objects*

- **Primitive** (single value)
- String - `"hello"`
- Number - `42, 3.14`
- Boolean - `true / false`
- undefined - declared, no value
- null - empty on purpose
- BigInt - `123n`
- Symbol - unique id

- **Reference** (collection)
- Object - `{ name: "Aman" }`
- Array - `[1, 2, 3]`
- Function - `function () {}`
- Arrays & functions are also objects
