# Truthy & Falsy

*Every value is treated as true or false in a condition*

---

## ❌ Falsy (only 8)

| Value | Note |
|---|---|
| `false` | |
| `0` | |
| `-0` | |
| `0n` | |
| `""` | empty string |
| `null` | |
| `undefined` | |
| `NaN` | |

---

## ✅ Truthy (everything else)

| Value | Note |
|---|---|
| `"0"`, `"false"` | |
| `[ ]` | empty array |
| `{ }` | empty object |
| any number except `0` | |
| functions | |
