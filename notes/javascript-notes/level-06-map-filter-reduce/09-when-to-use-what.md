# When to use what?

| Ask yourself | Use | Returns |
|---|---|---|
| Change every item? | **map** | new array, same length |
| Keep only some items? | **filter** | new array, smaller or same |
| One result from all items? | **reduce** | anything |
| Find one item? | **find** | item or undefined |
| Yes / no question? | **some / every** | true / false |

> **Note :** None of these change the original array.
