# Uses of Closures

- **Uses**
- Data privacy / encapsulation
- Module pattern
- Currying
- Memoization
- Debounce & throttle (Level 10)
- setTimeout & event handlers

- **Problems**
- Variables stay in memory
- Too many → memory leaks
- Remove unused event listeners
