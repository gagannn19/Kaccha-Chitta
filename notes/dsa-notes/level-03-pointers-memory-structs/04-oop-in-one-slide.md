# OOP in One Slide

- **Encapsulation** - keep data private, expose methods (getters / setters)
- **Inheritance** - `class Dog : public Animal` reuses Animal's code
- **Polymorphism** - same function name, different behaviour (overloading, `virtual` functions)
- **Abstraction** - show only what's needed, hide details (abstract classes with pure virtual functions)

> **For DSA :** For DSA you mostly need structs + comparators. OOP matters more in interviews' theory rounds.
