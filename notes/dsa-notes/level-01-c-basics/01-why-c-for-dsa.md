# Why C++ for DSA?

- **Fast** 

        C++ is often faster because:
        1. Compilation before execution: C++ is typically compiled into native machine code before the program runs.
        2. Memory control: C++ provides greater control over memory allocation and data layout.
        3. Static typing: We specify data types, such as `int`, `char`, and `double`, allowing the compiler to optimize the code effectively.
        Note: JavaScript also uses JIT compilation and can generate optimized machine code. Therefore, C++ isn't always faster, but it often performs very well in computationally intensive tasks such as DSA problems.

- **STL** - ready-made data structures & algorithms (vector, map, sort...)
- Used by most competitive programmers & accepted on LeetCode, Codeforces, GFG
- Teaches how memory really works (pointers, stack, heap)

> **For you :** JS is your language for web dev. C++ is your gym for DSA - same logic, much faster.
