# Operators & Type Casting

```cpp
7 / 2        // 3      int / int = int (decimal part dropped)
7 / 2.0      // 3.5
7 % 2        // 1      remainder - only for integers
-7 % 2       // -1     sign follows the left side

int x = 5;
x++;  ++x;  x += 3;
double avg = (double)sum / n;     // cast BEFORE dividing
int c = 'a' + 1;                  // 98
char next = 'a' + 1;              // 'b'
a == b, a != b, a && b, a || b, !a
```
