# What is Time Complexity?

*NOT seconds - the number of steps as input grows*

- Same code runs at different speeds on a laptop vs a phone - so we don't measure seconds
- We count **how many operations** the code does for input size **n**
- Then we keep only how it **grows** when n becomes very large

> **Example :** Searching your name in a register : checking one by one grows with the number of pages (O(n)). Opening the middle & halving each time grows much slower (O(log n)).
