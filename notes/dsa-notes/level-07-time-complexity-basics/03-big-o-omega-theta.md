# Big O, Omega & Theta

| Notation | Means | Linear search example |
|---|---|---|
| **O (Big O)** | upper bound - worst case | O(n) : element at the end / missing |
| **Ω (Omega)** | lower bound - best case | Ω(1) : element is first |
| **Θ (Theta)** | tight bound - exact growth | Θ(n) in the worst case |

> **In practice :** In interviews, 'what is the complexity?' almost always means Big O of the WORST case.
