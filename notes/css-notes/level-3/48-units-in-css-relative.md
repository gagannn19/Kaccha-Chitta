# Units in CSS : Relative

**Relative units** = size depends on **something else** (parent, root font, or screen). So it changes when that thing changes.

- `%` → relative to the **parent**
- `em` → relative to the **parent's font size**
- `rem` → relative to the **root (`<html>`) font size**
- `vh`, `vw` → relative to the **screen (viewport)**
