# Em

`em` = times the **font size**.

- For `font-size` → uses the **parent's** font size
- For other things (`width`, `padding`...) → uses the **element's own** font size

> Parent font-size is 20px → `font-size: 2em` = 40px.

⚠️ em **adds up** in nested elements (2em inside 2em = 4× bigger).
