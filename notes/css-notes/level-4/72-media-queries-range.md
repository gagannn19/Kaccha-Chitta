# Media Queries : range

<sub>Level 4 · Slide 72</sub>

```css
@media (min-width : 200px) and (max-width : 300px) {
    div {
        background-color : red;
    }
}
```

- `min-width: 200px` → screen is **at least** 200px
- `max-width: 300px` → screen is **at most** 300px
