# Alpha Channel

<sub>Level 2 · Slide 45</sub>

**opacity** (0 to 1)

**RGBA**

```css
color: rgba(255, 0, 0, 0.5);
color: rgba(255, 0, 0, 1);
```

![rgba output](../images/rgba.png)

> `opacity: 0.5` fades the **whole element** (text too). `rgba(...)` fades **only that color**.
