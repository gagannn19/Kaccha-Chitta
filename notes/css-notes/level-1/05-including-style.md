# Including Style

**Inline** : writing style directly inline on each element

```html
<h1 style="color: red"> Apna College </h1>
```

**`<style>` tag** : style is added using the `<style>` element in the same document

```html
<style>
    h1 {
        color: red;
    }
</style>
```
