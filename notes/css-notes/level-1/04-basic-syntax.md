# Basic Syntax

<sub>Level 1 · Slide 4</sub>

```css
h1 {
    color: red;
}
```

- `h1` → **Selector**
- `color` → **Property**
- `red` → **Value**

> The semicolon `;` shows that one property has ended. Always put it, even though missing it on the last line won't give an error.
