Why Do We Need React?

A website mainly uses three technologies:

* HTML: Creates the structure. (Headings, buttons, images)
* CSS: Makes the website look beautiful. (Colors, sizes, layouts)
* JavaScript: Adds functionality and interactivity. (Clicking buttons, calculations, etc.)

 Can JavaScript do everything React does?
 Yes! JavaScript can build interactive websites without React.

imagine a shopping website with an Add to Cart button.
Imagine you click the Add to Cart button.
Using JavaScript, you might write:

let count = 0;

function addToCart() {
  count++;

  document.getElementById("cart").innerText = count;
}
